Student Management System

A command-line application built with Python and SQLite to manage student records.

Features

* Add new students
* Display all student records
* Search students by name
* Delete student records
* Prevent duplicate email addresses
* Validate user input
* Store data in an SQLite database

Technologies

* Python 3
* SQLite
* SQL
* Git and GitHub

Concepts Demonstrated

* Functions and modular programming
* Database design and CRUD operations
* SQL queries and parameterized statements
* Exception handling and input validation

How to Run

1. Install Python 3.
2. Clone this repository.
3. Open a terminal in the project folder.
4. Run:

python main.py

The database and students table are created automatically when the application starts.
